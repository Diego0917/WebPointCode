## 📦 Dependencias del Proyecto

Este proyecto está construido con React, Vite, Tailwind CSS y herramientas modernas para la interfaz y navegación. A continuación se detallan las dependencias instaladas:

### 🚀 Dependencias de Producción (`dependencies`)
- **`react`** (^18.x o superior) — Biblioteca principal para la creación de componentes de interfaz de usuario.
- **`react-dom`** (^18.x o superior) — Manejador de renderizado para DOM en React.
- **`react-router-dom`** (^6.x o superior) — Enrutador para gestionar la navegación multipágina (`/`, `/desarrollo`, `/diseno`).
- **`lucide-react`** — Biblioteca de iconos vectoriales minimalistas (`Menu`, `X`, `Phone`, `Mail`, `MapPin`, `Code`, `Palette`, `ArrowRight`, etc.).

### ⚙️ Dependencias de Desarrollo (`devDependencies`)
- **`tailwindcss`** (^4.x) — Motor de estilos CSS utilitario.
- **`@tailwindcss/vite`** — Plugin oficial de integración de Tailwind CSS con Vite.
- **`vite`** — Entorno de desarrollo ultrarrápido y empaquetador para el proyecto.

---

### 📥 Comando de Instalación Rápida
Si necesitas reinstalar todas las dependencias desde cero en un nuevo entorno, ejecuta el siguiente comando en tu terminal:

```bash
npm install react react-dom react-router-dom tailwindcss @tailwindcss/vite lucide-react
